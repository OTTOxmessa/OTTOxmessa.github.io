## Overview

A table and board game booking system for a café, built to the team's Plan.docx spec.

## What I own

- **Collection** — the café's game library
- **Plays** — logging each play session
- **Reviews** — game reviews and ratings
- **Stats** — statistics built with MongoDB aggregation pipelines

## Teamwork

Everyone works on their own branch and merges into `Develop` before it goes to `main`.
